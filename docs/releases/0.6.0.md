# Virkey 0.6.0

## Highlights

- Remember the last Wi-Fi PC and selected Bluetooth/Wi-Fi mode. Pair once with
  a PIN and verified fingerprint, then tap **Reconnect** without re-entering it.
- Persist the host identity, protect reconnect credentials and detect changed
  certificates. **Forget PC** and **Reset pairing** remove remembered trust.
- Add a customizable dock with up to 24 PC app or soundboard hotkey buttons.
  Use automatic Windows icons or your own images; rename and reorder buttons.
- Expand the glass-style media player with larger artwork. Enable optional
  LRCLIB lyrics, including timed highlighting and supported tap-to-seek.
- Show the Virkey logo on the Windows EXE, application windows and system tray.
- Refresh all interface previews and setup, privacy, recovery and testing guides.

This release includes the work tested locally as 0.4.0 and 0.5.0; those versions
were not published as separate GitHub releases. Bluetooth remains the first-run
default and needs no PC receiver. Wi-Fi features use the portable Windows host.

## Upgrade

1. Install the APK over the existing Virkey app to preserve its data.
2. Fully exit the previous Windows host from its tray menu, then run the new EXE.
3. Start hosting and pair once using the PIN and matching fingerprint. Later
   connections use **Reconnect** without a PIN; automatic connection on launch
   is intentionally not enabled.

See [installation and device checks](https://github.com/zhenxxx7/virkey/blob/v0.6.0/docs/testing-0.6.0.md)
and [pairing recovery](https://github.com/zhenxxx7/virkey/blob/v0.6.0/docs/reconnect-0.6.0.md).

## Validation and limitations

Android assemble, 178 automated tests and lint pass. The Windows publish and
11 self-test groups pass, including persistent pairing, real loopback TLS
reconnect, revocation, input safety and the multi-resolution icon. These checks
do not replace tablet-to-PC testing. See the
[validation report](https://github.com/zhenxxx7/virkey/blob/v0.6.0/docs/validation-0.6.0.md).

The APK is development-signed for testing, despite its clean filename. The EXE
is unsigned and may show a Windows reputation prompt. Wi-Fi requires the same
reachable local network. Lyrics are optional and send track metadata to LRCLIB
only when enabled; coverage varies. Soundboard buttons send configured hotkeys
to an existing PC application, not audio. USB and other desktop OS support are
not included.
